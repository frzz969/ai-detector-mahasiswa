# Referensi 7 — Kohesi & Koherensi (Aquariza 2018)

Sumber: Aquariza, N. R. (2018). Penguasaan Kohesi dan Koherensi dalam
Tulisan Narasi Siswa SMK di Surabaya. *Reforma: Jurnal Pendidikan dan
Pembelajaran*, 7(1), 41–45. DOI: 10.30736/rf.v7i1.201.
(Keberadaan terverifikasi via Garuda Kemdikbud + situs jurnal Unisla;
isi disarikan dari tempelan user.)

Status file ini: **landasan interpretasi** (lihat
`validation-rules.md` §51) — definisi kohesi/koherensi untuk menilai
kualitas hubungan antarkalimat, BUKAN aturan `keyword = AI`.

## 1. Definisi operasional untuk mesin

- **Kohesi** = keterpautan BENTUK (gramatikal & leksikal): konjungsi,
  referensi, substitusi, ejaan, struktur.
- **Koherensi** = keterpautan MAKNA: kelengkapan gagasan, alur pikir
  tanpa lompatan, orientasi pada pokok utama.
- Keduanya syarat tulisan ideal; detector menilai hubungan
  antarkalimat/paragraf (§5 prompt final), bukan kata lepas.

## 2. Temuan error manusia (BUKAN bukti AI)

Penelitian menemukan pada tulisan siswa: kalimat tidak tuntas,
kalimat pendek yang membingungkan (BUKAN kalimat efektif),
peletakan konjungsi tidak tepat, kata/frasa nonformal ("ngajar",
"bikin kangen"), salah eja ("mulay", "sekor"), pengaruh bahasa daerah
("keturutan"), ide tidak berkembang. Ini pola **tulisan manusia** —
bila detector menemukan error semacam ini, JANGAN naikkan skor AI.

## 3. Catatan penting untuk detector

- Kalimat pendek ≠ kalimat efektif: rangkaian kalimat pendek yang
  idenya belum berkembang = paragraf tidak kohesif (dukung sinyal
  variasi + keunikan, bukan vonis).
- Konjungsi ("karena itu", "dengan demikian", "jadi", "akibatnya",
  "oleh sebab itu") adalah SYARAT kohesi (Dalman 2014) — kehadiran +
  ketepatannya dinilai, bukan keberadaannya dihukum. Sejalan dengan
  frequency guard: hanya pola berulang yang ditinjau.
- Orisinalitas ide (tulisan dari pengalaman sendiri) = sinyal
  kemanusiaan: apresiasi, jangan flag. Dukung voice/specificity.

## 4. Panduan untuk humanizer

- Perbaiki kohesi: konjungsi tepat + tanda baca benar; kembangkan ide
  pendek yang menggantung; JANGAN meniru gaya nonformal/sosmed.
- Baca ulang + revisi wajib (Dalman 2014:57) — dukung alur review
  aplikasi (cek → perbaiki → cek ulang).
- Ejaan/struktur benar = kredibilitas; jangan korbankan demi skor.

## 4. Batasan (penomoran mengikuti naskah sumber)

- Objek penelitian: narasi siswa SMK (bahasa Indonesia); generalisasi
  ke skripsi/makalah bersifat analogi.
- Jangan mengklaim artikel ini sebagai "penelitian sistem ini".
